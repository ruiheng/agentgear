# Search Files

Choose only capabilities useful for the question and corpus. The runtime sections below are independent candidates, not a preferred sequence.

- Match capabilities to the information being sought: paths, text content, document structure, source syntax, or cross-file relationships.
- A built-in capability may be better, and tool availability never grants permission.
- Keep search operations read-only unless the task explicitly requires a change.
- Report the evidence used and material coverage gaps; do not imply complete corpus coverage from a partial search.

This is ordinary information retrieval across local files, not a full audit, defect-family analysis, code-health review, or authorization to edit.
